# New photos go here

Upload new photos to this folder (Add file → Upload files on GitHub).

For each photo, tell Claude:
- the animal
- where it was taken (city / place)
- the room it should be shown in first (living room, bathroom, office…)

Use **web-size copies** (about 2000 px on the long side).
Never upload the full-size print files here: this repository is public.

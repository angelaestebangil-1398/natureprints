# NaturePrints

Fine art prints of the wild life living around us, printed in Barcelona and shipped worldwide.
Collection 01: **Wildly Yours**, from Barcelona, Paris and Chamonix.

## How the site works
A plain HTML/CSS/JavaScript website, no platform or build step.

| File | What it is |
|---|---|
| `products.js` | **Edit this one**: shop name, prints, prices, sizes, places |
| `index.html` | Home page |
| `shop.html` | Shop with filters (animal, place) |
| `product.html` | Print page (works for every print) |
| `story.html` | Our story |
| `policies.html` | Shipping, returns, privacy |
| `styles.css` / `site.js` | Design and logic |
| `images/` | Website photos (web size) |
| `new-photos/` | Drop new photos here |
| `overview/photo-numbers.jpg` | All photos with their numbers |

## See it locally
Open `index.html` in a browser.
